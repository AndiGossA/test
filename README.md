# Lifestyle App

A personal lifestyle planning project.

## Contents

- [`index.html`](./index.html) — Landing page, published with GitHub Pages.
- [`lifestyle-plan.md`](./lifestyle-plan.md) — Personal roadmap from August 2026
  through the end of 2027, covering budgeting, personal goals, career
  development, and skill development. Reviewed monthly and updated each
  quarter.

## Usage

Open `lifestyle-plan.md` and fill in the placeholder fields (marked `___`)
with your own figures and goals. Follow the review cadence in Section 7 of
that document to keep it up to date.

## Style

The landing page follows the design system in
[AndiGossA/style](https://github.com/AndiGossA/style) — palette, typography
and component conventions live there, in `PREFERENCES.md`, `tokens.css` and
`base.css`. The page carries its own copy of the CSS inline so it stays a
single self-contained file; if you change a token there, bring the change back
here too.
