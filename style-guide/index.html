Usage

Copy tokens.css and base.css into a project, load the fonts, and write plain HTML.

<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&family=Source+Serif+4:opsz,wght@8..60,400;8..60,600&display=swap" rel="stylesheet">
<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="base.css">

House rules

  • Never hard-code a colour. Every value lives in tokens.css; override on :root if a project needs to differ.
  • Serif carries meaning, sans carries function. Headings, figures and keys are serif; navigation, body, buttons and labels are sans.
  • Alternate the grounds. Sections run --paper, then .band, then back — closing with a .band-dark call to action.
  • One accent per element. Pink for labels and detail, brown for action and structure. Don't mix both in a single mark.
  • Only --rose-600 carries text. The lighter pinks fail contrast at label sizes — keep them on rules, dots and fills.
  • Keep the measure. Body copy at 62ch, ledes at 54ch, headlines at about 15ch.
  • Accessibility is a floor, not a finish. Measured on --paper: body text 13.0:1, muted text 5.4:1, --rose-600 labels 5.2:1, --brown-700 links 8.2:1 — all AA or better. Check any new pairing before shipping it.
